# 비바온 (VIVA ON) 앱 내려받기

50+ 건강생활 플랫폼 **비바온** 안드로이드 앱 시제품을 내려받는 곳입니다.

## 내려받기

👉 **[최신 버전 내려받기](https://github.com/finekim67-dot/viva-on-release/releases/latest)**

릴리스 페이지 아래쪽 **Assets**에서 파일을 고르세요.

| 파일 | 언제 쓰나요 |
|---|---|
| `viva_on_release.apk` | 휴대폰에서 바로 눌러 설치 |
| `viva_on_release_v버전.zip` | 카카오톡·메일로 보낼 때 (APK 파일이 막히는 경우). 압축을 풀면 APK가 나옵니다 |

## 설치 방법 (안드로이드)

1. 휴대폰에서 `viva_on_release.apk`를 내려받아 누릅니다.
2. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 다시 설치합니다.
3. 앱을 열고 **MY 탭 → 서버 연결**에서 안내받은 서버 주소를 넣습니다.
4. 걸음 수 연동을 위해 **헬스 커넥트(삼성헬스)** 권한을 허용합니다.

## 알아두세요

- 정식 출시 전 **시제품**입니다. 결제는 실제로 이루어지지 않는 **테스트 결제**입니다.
- 지금은 **안드로이드만** 지원합니다.
- 이 저장소에는 설치 파일만 있습니다.
