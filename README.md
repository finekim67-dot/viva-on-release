# 비바온 (VIVA ON) 앱 내려받기

50+ 건강생활 플랫폼 **비바온** 안드로이드 앱 시제품을 내려받는 곳입니다.

## 내려받기

👉 **[최신 버전 내려받기](https://github.com/finekim67-dot/viva-on-release/releases/latest)**

릴리스 페이지 아래쪽 **Assets**에서 파일을 고르세요.

| 파일 | 언제 쓰나요 |
|---|---|
| `viva_on_release.apk` | 휴대폰에서 바로 눌러 설치 |
| `viva_on_release_v버전.zip` | 카카오톡·메일로 보낼 때 (APK 파일이 막히는 경우). 압축을 풀면 APK가 나옵니다 |

## 설치 방법 (안드로이드 14·15·16 기준)

갤럭시(One UI 6~8) 화면 이름을 기준으로 적었습니다. 휴대폰마다 메뉴 이름이 조금 다를 수 있습니다.

### 1. 내려받기
- 휴대폰의 Chrome이나 삼성 인터넷에서 `viva_on_release.apk`를 누릅니다.
- "이 파일은 유해할 수 있습니다" 안내가 나오면 **[그래도 다운로드]** 를 누릅니다.
- 카카오톡으로 받았다면 zip 파일을 **내 파일** 앱에서 눌러 압축을 풀고, 나온 APK를 누릅니다.

### 2. 설치 허용
- 처음 설치하면 "보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다"라고 나옵니다.
- **[설정]** 을 누르고 **이 출처 허용**을 켠 뒤 뒤로 가기를 눌러 다시 설치합니다.
  - 허용하는 대상은 파일을 연 앱(Chrome·삼성 인터넷·내 파일·카카오톡)입니다.
  - 나중에 끄려면: 설정 → 애플리케이션 → (그 앱) → **출처를 알 수 없는 앱 설치**.

### 3. "자동 차단"이 켜져 있으면 (갤럭시)
- "자동 차단 때문에 설치가 차단되었습니다"라고 나오면 잠시 꺼야 합니다.
- 설정 → **보안 및 개인정보 보호** → **자동 차단**을 끄고 다시 설치합니다.
- 설치가 끝나면 다시 켜 두세요.

### 4. Play 프로텍트 안내
- "Play 프로텍트에서 이 앱을 차단했습니다" 또는 "안전하지 않은 앱"이라고 나올 수 있습니다. 아직 Play 스토어에 올리지 않은 시제품이라 나오는 안내입니다.
- **[세부정보 더보기]** → **[무시하고 설치]** 를 누릅니다.
- "앱을 검사하도록 보낼까요?"는 어느 쪽을 골라도 괜찮습니다.

### 5. 처음 실행과 권한
1. 앱을 열면 첫 화면에서 고릅니다.
   - **처음이에요 (회원가입)**: 휴대폰 번호, 이름, 시험 초대 코드(안내받은 경우)를 넣고 약관에 동의합니다.
   - **이미 가입했어요 (로그인)**: 가입한 휴대폰 번호로 들어옵니다.
   - **가입 없이 둘러보기**: 예시 화면만 봅니다 (위에 '시연 중' 표시, 포인트·주문은 저장되지 않음).
   - 서버 주소는 앱에 미리 들어 있습니다. 안내받은 주소가 다를 때만 가입·로그인 화면의 **고급 설정**에서 바꿉니다.
2. **신체 활동** 권한은 **허용**합니다. 휴대폰 만보기로 걸음 수를 셉니다.
3. **헬스 커넥트** 화면에서 **걸음 수** 읽기를 허용합니다.
   - 안드로이드 14 이상은 헬스 커넥트가 휴대폰에 들어 있습니다. 설정 → 보안 및 개인정보 보호 → 개인정보 보호 → **헬스 커넥트**.
4. 삼성헬스 걸음 수를 쓰려면 삼성헬스 앱 → 설정 → **헬스 커넥트**에서 걸음 수 내보내기를 켭니다.
5. 걸음 수가 늦게 올라가면: 설정 → 애플리케이션 → 비바온 → 배터리 → **제한 없음**으로 바꿉니다.

### 새 버전으로 바꿀 때
- 지우지 말고 새 APK를 그대로 설치하면 됩니다. 포인트·주문 기록은 서버에 있어 그대로 남습니다.
- v0.6.0부터 처음 화면이 로그인 화면으로 바뀌었습니다. 예전에 '서버 연결'로 쓰던 번호로 **[이미 가입했어요 (로그인)]** 하면 기록이 그대로 보입니다.
- "기존 패키지와 충돌하여 설치되지 않았습니다"라고 나오면 예전 비바온 앱을 지우고 설치하세요.

### 안드로이드 13 이하
- 안드로이드 8.0 이상이면 설치할 수 있습니다.
- 헬스 커넥트가 휴대폰에 없으면 Play 스토어에서 **헬스 커넥트** 앱을 설치하세요.
