## 📱 화면별 자세한 안내

갤럭시(안드로이드 14·15·16, One UI 6~8) 화면 이름 기준입니다. 휴대폰마다 메뉴 이름이 조금 다를 수 있어요.

<a name="download"></a>
<details open>
<summary><b>1. 내려받기</b></summary>

- 휴대폰의 **Chrome** 또는 **삼성 인터넷**에서 내려받기를 눌러요.
- "이 파일은 유해할 수 있습니다"가 나오면 [**그래도 다운로드**]를 눌러요. (아직 Play 스토어에 올리지 않은 앱이라 나오는 안내예요)
- **카카오톡으로 받았다면**: zip 파일을 **내 파일** 앱에서 눌러 압축을 풀고, 나온 `viva_on_release.apk`를 눌러요.

</details>

<a name="allow"></a>
<details open>
<summary><b>2. 설치 허용</b></summary>

- "보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다"가 나오면 [**설정**]을 눌러요.
- **이 출처 허용**을 켜고 ◀ 뒤로 가기 → 다시 [**설치**]를 눌러요.
- 허용하는 대상은 파일을 연 앱(Chrome·삼성 인터넷·내 파일·카카오톡)이에요.
- 나중에 끄려면: 설정 → 애플리케이션 → (그 앱) → **출처를 알 수 없는 앱 설치**

</details>

<a name="autoblock"></a>
<details>
<summary><b>3. 자동 차단 (갤럭시)</b> — "자동 차단 때문에 설치가 차단되었습니다"가 나올 때</summary>

- 설정 → **보안 및 개인정보 보호** → **자동 차단**을 잠시 꺼요.
- 설치한 뒤에는 **다시 켜 두세요.**

</details>

<a name="protect"></a>
<details>
<summary><b>4. Play 프로텍트</b> — "Play 프로텍트에서 이 앱을 차단했습니다"가 나올 때</summary>

- [**세부정보 더보기**] → [**무시하고 설치**]를 눌러요.
- "앱을 검사하도록 보낼까요?"는 어느 쪽을 골라도 괜찮아요.

</details>

<a name="first-run"></a>
<details open>
<summary><b>5. 처음 실행</b></summary>

1. 첫 화면에서 골라요.
   | 버튼 | 이런 분 |
   |---|---|
   | **처음이에요 (회원가입)** | 처음 쓰는 분 — 휴대폰 번호(자동으로 불러옴), 이름, **시험 초대 코드**, 약관 동의 |
   | **이미 가입했어요 (로그인)** | 전에 가입한 분 — 같은 휴대폰 번호와 **시험 초대 코드** |
   | **가입 없이 둘러보기** | 화면만 구경 — 위에 "시연 중" 표시, 포인트·주문은 저장되지 않아요 |
2. **글자 크기**(보통·크게·아주 크게)를 골라요. 나중에 **MY 탭 → 글자 크기**에서 바꿀 수 있어요.
3. **신체 활동** 권한을 **허용**해요. 휴대폰 만보기로 걸음을 셉니다.
4. **헬스 커넥트**에서 **걸음 수** 읽기를 허용해요.
   - 안드로이드 14 이상은 휴대폰에 들어 있어요: 설정 → 보안 및 개인정보 보호 → 개인정보 보호 → **헬스 커넥트**
5. **삼성헬스** 걸음을 쓰려면: 삼성헬스 → 설정 → **헬스 커넥트**에서 걸음 수 내보내기를 켜요.

</details>

## 🔄 새 버전으로 바꾸기

- **지우지 말고** 새 APK를 그대로 설치하면 돼요. 포인트·주문 기록은 서버에 있어 그대로 남아요.
- 서버가 바뀐 버전을 설치하면 첫 화면으로 돌아가요. [**이미 가입했어요 (로그인)**]으로 같은 번호를 넣으면 기록이 그대로 보여요.
- 버전마다 바뀐 내용은 [릴리스 목록](https://github.com/finekim67-dot/viva-on-release/releases)에서 볼 수 있어요.

## 🛠 이럴 땐 이렇게

<details>
<summary><b>"기존 패키지와 충돌하여 설치되지 않았습니다"</b></summary>

예전 비바온 앱을 지우고 새로 설치해요. 포인트·주문 기록은 서버에 있어 로그인하면 다시 보여요.
</details>

<details>
<summary><b>"시험 초대 코드가 맞지 않습니다"</b></summary>

안내받은 코드를 다시 확인해 주세요. 대·소문자는 구분하지 않아요. 코드를 모르면 담당자에게 문의하세요.
</details>

<details>
<summary><b>"가입되지 않은 번호예요"</b> / <b>"이미 가입된 번호예요"</b></summary>

화면 아래에 나오는 [**이 번호로 회원가입**] 또는 [**이 번호로 로그인**] 버튼을 눌러요.
</details>

<details>
<summary><b>걸음 수가 안 올라가거나 늦게 올라가요</b></summary>

- 설정 → 애플리케이션 → 비바온 → **권한**에서 **신체 활동**이 허용됐는지 확인해요.
- 설정 → 애플리케이션 → 비바온 → 배터리 → **제한 없음**으로 바꿔요.
- 삼성헬스 걸음을 쓰면 삼성헬스 → 설정 → 헬스 커넥트 연결을 확인해요.
</details>

<details>
<summary><b>휴대폰 번호가 자동으로 안 나와요</b></summary>

유심이 없거나 구글 Play 서비스가 없는 휴대폰에서는 번호 선택 창이 뜨지 않아요. 번호를 직접 입력하면 돼요.
</details>

<details>
<summary><b>안드로이드 13 이하 휴대폰</b></summary>

안드로이드 8.0 이상이면 설치할 수 있어요. 휴대폰에 헬스 커넥트가 없으면 Play 스토어에서 **헬스 커넥트** 앱을 설치하세요.
</details>
